***Tak for din henvendelse***

Vi bestræber os på at hjælpe så hurtigt som muligt inden for de givne rammer og takker for jeres tålmodighed og forståelse.

Der er på nuværende tidspunkt ikke tilknyttet en kommerciel supportfunktion til OS2samtale. Supporten varetages derfor af sekretariatet, hvilket betyder at svartiden kan variere. 

Supportfunktionen er åben to timer om ugen hvor vi håndterer indkomne forespørgsler:
 - Brugere oprettes som udgangspunkt én gang om ugen, typisk fredag.
 - Anmodninger om nyt password håndteres inden for support funktionens åbningstid, hvilket kan medføre lang ventetid.
    - Fejlmeldinger oprettes på Github, med informativ note  til support teamet for hurtigere sagsbehandling
        -Github Issues oprettes her:[https://github.com/OS2sandbox/sandbox-samtale/issues](https://github.com/OS2sandbox/sandbox-samtale/issues)
    - Support teamet kontaktes via  OS2samtale@os2.eu 

I er naturligvis også meget velkomne til at bruge samtalechatten til at dele viden, tips og tricks – eller give hinanden lidt venlig support.

Tak for jeres tålmodighed.
